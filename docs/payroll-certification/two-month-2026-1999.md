## Actual execution and result contract

The dedicated `payroll-1999-two-month.yml` checks out the exact proposed head, provisions new disposable PostgreSQL **16 and 18**, uses random fictional encryption keys and keeps protected money/provider/history/CSP flags OFF. It does not reuse a developer database, call Neon, run repository migrations, contact providers or file with an agency.

Each run uses the actual enqueue/drain engine, persisted entries and payslip text. A synthetic state transition invokes actual `settlePayrollRun` to release **records only**, preserving first-cutoff evidence for the true-up and next-month checks. This is **not** an approval-authorization, independent-checker or UI journey test. Previous released entries must remain unchanged after subsequent runs. The actual journal builder and CSV writer are compared against separate expected gross, deductions control and net-payable amounts; the existing journal represents those controls, not a full statutory-liability GL account mapping.

The artifact `payroll-1999-pg16` / `payroll-1999-pg18` contains `result.json`: exact source SHA, month/cutoff/worker/component, expected/actual/signed integer-centavo delta, monthly worker totals, exported journals, structural failures, explicit source holds and release boundaries. The complete fixture yields **32 worker-cutoff observations and 500 detailed comparisons**, plus monthly summaries. Artifacts are written even when a mismatch or structural error fails the job; an early error marks unexecuted monthly observations `NOT RUN`.

- `AGREES`: exact arithmetic match under the stated input/collection assumptions; not certification.
- `DISAGREES`: any nonzero centavo delta; **even PHP0.01 is retained and fails the parity gate**. No permissive tolerance or rewritten expected value.
- `SOURCE NOT VERIFIED`: explicit unverified source/rounding interpretation, including matching PH observations. Dependent tax/net comparisons are arithmetic under that same assumption, not independent resolution of it.
- `NOT RUN`: missing cutoff/component evidence. A skipped DB test is not an executed payroll month.
