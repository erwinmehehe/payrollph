## Current-date wage screening exception — Region VI effective 2026-11-20

**SOURCE READ / IMPLEMENTATION FOLLOW-UP REQUIRED (not part of the fictional July/September NCR test):** Official [NWPC Region VI source](https://nwpc.dole.gov.ph/region-vi/) and [Wage Order VI (Western Visayas)-30](https://nwpc.dole.gov.ph/wp-content/uploads/2026/11/WAGE-ORDER-NO.-VI-WESTERN-VISAYAS-30.pdf), issued **2026-10-21**, published **2026-11-04**, **effective 2026-11-20**, establish **₱590/day** for non-agriculture/industrial/commercial employers with **more than 10 workers**, and **₱565/day** for non-agriculture employers with **10 or fewer workers** and covered agriculture workers. These are categories, **not one universal wage**. A separate domestic-worker order effective the same day sets **₱7,000/month**, outside the ordinary covered class in this test.

At the time of this review, `src/lib/wage-orders.ts` on `main` still identifies the Region VI screening entry as **WO-RBVI-29, ₱550/day, effective 2025-11-19**, and explicitly dates its source snapshot to **2026-11-16**, before VI-30 took effect. Therefore a **new 2026-11-20+ effective-date implementation / payroll source review** is required before using the screening registry as current for a Region VI work day. Existing effective-dated historical work must retain historical rates. **Do not update the runtime wage registry in this source-only PR**, because changing wage imports invalidates source-bound tenant security evidence and requires separate source/proof review. Track as a distinct regional-wage implementation review; do not claim this PR fixes minimum-wage screening.

**No rule is marked independently certified** merely because a government publication is accessible or a synthetic test passes. If the employer classification, later circular, source of basic salary, odd-cent policy, historical posting state, or correction channel is uncertain, record **SOURCE NOT VERIFIED** and refuse unattended financial posting.
