# Region VII wage order transition — as-of screening only

Official NWPC announcement 2026-09-29:
https://nwpc.dole.gov.ph/central-visayas-workers-set-to-receive-%E2%82%B142-minimum-wage-increase-wage-review-in-other-regions-ongoing/

On **2026-10-10**, the current Class A high-tier screening reference remains
WO-ROVII-26, effective 2025-10-04: PHP 540/day. The published WO-ROVII-27
is effective **2026-10-14** and increases the Class A maximum to PHP 582/day,
Class B to PHP 542/day. It must NOT be prematurely applied on Oct 10.

The wage check used by the payroll engine now resolves an explicit **pay
date**. The new highest-tier advisory reference starts 2026-10-14.
This screen never sets salary automatically, changes employee MWE status
or substitutes for legally required Class A/B, industry and local wage review.
Payroll spans across the effective-date boundary require separate daily
legal assessment; the single screening reference is not a tranche-aware
individual worker wage entitlement calculation.

Other future regional tranches remain outside this patch until primary
source confirmation and exact scope/tier evidence are captured.
